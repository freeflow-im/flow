**New in 0.2.39**

- **Updates come from MCP Docs' new home**: the app's **Check for Updates…** and the `npx @freeflow-im/mcp-docs` installer now look in the FreeFlow repository (github.com/freeflow-im/flow), where MCP Docs is developed and released from now on. This is the last version published in the old repository as well; install it and later updates arrive by themselves.
- **The assistant shows pictures in the chat**: a picture it finds, makes or looks at appears in the conversation itself.
- **The assistant runs again after an unreadable search key**: a saved Brave Search key that could not be read no longer stops every turn.
