**New in 0.2.40**

- **Opening a file no longer gives an empty tab**: a folder's server that had stopped answering left every tab opened on it blank, most often for a download in Downloads or a file double-clicked in the Finder. The app now notices and starts a fresh one, and a page that cannot load says why instead of staying blank. The app also keeps a log (**~/Library/Logs/MCP Docs** on a Mac) for problems like this.
- **Updates come from MCP Docs' new home**: the app's **Check for Updates…** and the `npx @freeflow-im/mcp-docs` installer now look in the FreeFlow repository (github.com/freeflow-im/flow), where MCP Docs is developed and released from now on. This is the last version published in the old repository as well; install it and later updates arrive by themselves.
- **The assistant shows pictures in the chat**, and runs again after an unreadable search key.
