**New in 0.2.12**

- **New Tab (⌘T):** File › New Tab (or the + in the tab bar) opens a tab on the same folder, showing the same list.
- **A folder for each tab:** opening a folder (Open Folder…, Open file by path…, a file in Recents) changes only the tab you are in; your other tabs keep their folders. A file opened from Finder that is not in the folder in front opens in a new tab.
- Agents connected over MCP work on the folder of the tab in front.
- The window no longer shows "Universal Docs" for a moment as the app starts.
