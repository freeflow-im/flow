**New in 0.2.42**

- **The assistant floats over your file.** It starts as a small "AI Help" button in the bottom-right corner. Click it to chat in a floating panel, make the panel bigger, or anchor it beside your file as before; the app remembers how you left it. The floating panel tucks itself away after two quiet minutes, and closing the assistant ends the conversation, so it opens fresh next time.
- **File thumbnails show up again.** In a folder with many PDFs and videos the thumbnails filled in slowly or stayed blank, more so with several windows open. They now load a few at a time, visible ones first, and a PDF's thumbnail reads only the part of the file its first page needs.
