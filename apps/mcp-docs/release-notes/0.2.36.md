**New in 0.2.36**

- **New files open by themselves**: a file that appears in Downloads, Documents or Desktop (a download that finishes, a file saved from another app, a screenshot) opens in MCP Docs, and the app comes to the front. Several files at once (a copy) open nothing.
- **Choose what opens**: Settings has a Desktop tab to turn it off, and to pick the kinds of file: Word, Excel and PowerPoint files, PDFs, Markdown, CSV, other text files, pictures and videos (videos are off at first).
- **A File menu for every file**: pictures, PDFs, text and YAML files, JSON, web pages and videos have the editors' File menu: Open, Open in Finder, Rename, Download, Delete, and what the file offers (Edit picture, Sign or add text, Convert to Markdown, Download as PDF).
- **Web search without a Brave key**: the assistant's web and image search use your Brave Search key from Settings when you add one, and otherwise the web search of Anthropic or OpenAI when the assistant runs on them.
