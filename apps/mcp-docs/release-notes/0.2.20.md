**New in 0.2.20**

- **Web tabs at a new address:** Web tabs now open MCP Docs on the web at mcpdocs.freeflow.im. Your account and files are already there. Web tabs remember their own sign-in, so the first one after updating asks you to sign in again; Google sign-in works too.
- **Tail a log:** a text file that is still growing, such as a log, can be followed with **Tail**. New lines appear as they are written.
