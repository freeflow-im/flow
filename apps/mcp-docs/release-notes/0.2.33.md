**New in 0.2.33**

- **Favorites**: keep the folders and files you use most a click away. A new Favorites tab sits beside Recents on the home page; add anything to it with its menu (⋮) › Add to Favorites.
- **Star a file from its editor**: every editor's header starts with a star. Click it to add the file to your Favorites, or take it off. The file list has one too, for the folder you're in.
- **File › Open**: one menu with Open Folder…, Open file by path…, and your Favorites and Recents to pick from. Each opens in a new tab, so the file you're working on stays put.
- In the desktop app your Favorites are the same in every folder you open, and one in another folder opens in a tab on that folder.
