**New in 0.2.18**

- **Hidden files and folders:** the folder list now shows dot files and dot folders, such as `.env`, `.env.example`, `.gitignore`, `.git`, `.github` and `.config`. Text files among them, like YAML and other config files, open in the plain-text editor (⌘S saves). Search finds them too, but doesn't look inside `.git`. Open file by path… takes any file, hidden or not.
- **File extensions shown:** every file in the list shows its full name, extension included (`Plan.docx`, `notes.md`). Renaming keeps the extension whether you type it or not, and files made from a title (downloads, PDFs, exports, web copies) aren't named twice: a CSV file that becomes an Excel file is `stock.xlsx`, not `stock.csv.xlsx`.
- **One name:** the web version is now called MCP Docs too.
