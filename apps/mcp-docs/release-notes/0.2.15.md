**New in 0.2.15**

- **Codex:** the installer (`npx @scottpersinger/mcp-docs`) now offers the MCP Docs plugin for Codex as well as Claude Code, asking for each one it finds (`--claude`, `--codex` or `--yes` choose without asking). In Codex, sign in once with `codex mcp login mcp-docs`.
- **Any MCP client:** the installer prints the app's MCP address, `http://127.0.0.1:39217/mcp`, which any MCP client that supports streamable HTTP and OAuth can connect to while the app is running.
- An update no longer tells you to sign in again; only a first install does.
- **JSON viewer:** a JSON file opens as a tree, fully expanded, with Collapse all / Expand all and a triangle on each object and array. Edit switches to the text editor.
