**New in 0.2.31**

- **Find a file looks everywhere in your home folder**: ⌘P (Ctrl+P on Windows) lists the matches in the open folder first, then those anywhere else in your home folder (Documents, Downloads, your projects). Opening one moves to its folder, or Open ↗ opens it in a new tab.
- **Search by the end of a path**: type a folder and a name, `backend/.env` or `btdash/docker-compose.yaml`, to find that file in a folder of that name. Hidden files such as `.env` are found too.
- **Find a file from the home page**: ⌘P and the search button now work on the file list as well as in the editors.
- **Find in text files** (⌘F): logs, config files and source code get the find bar, with every match highlighted, Enter and Shift+Enter to step through them, and Match case. It works while Tail follows a log.
