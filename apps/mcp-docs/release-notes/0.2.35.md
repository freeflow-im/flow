**New in 0.2.35**

- **Settings has two tabs, Assistant and Connect your agent**: the Connect your agent tile on the home page, and File › Connect an Agent (MCP)… in the desktop app, open the second tab. It replaces the desktop app's Connect an Agent dialog.
- **The right MCP address**: in the desktop app the tab shows its own server on this computer, with a button to copy the Claude Code command; on the web, the hosted address. It warns when the desktop app's MCP server isn't running.
- **Disconnect one agent at a time**: the desktop app lists each agent you allowed, with its own Disconnect button.
- **Try it!**: a box on the Assistant tab sends a prompt to the assistant with your saved settings, so you can check a key right away. The answer shows in the Assistant panel.
