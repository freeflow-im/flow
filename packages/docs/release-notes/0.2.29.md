**New in 0.2.29**

- **Find a file** (⌘P, Ctrl+P on Windows): a search button in every editor's header. Before you type it lists the files you last opened in the app; typing searches every folder by name. Enter opens the file, Open (or ⌘/Ctrl+Enter) opens it in a new tab.
- **Rename from the title** in every editor, pictures, PDFs and text files included: click the file's name in the header and type.
- **Follows changes made by other apps**: the file list updates when files are added, removed or renamed in the folder, and an open file reloads when another program (or an agent) changes it on disk.
- **Folders fold away** in the file list: a folder's folders are one row you open when you need them, so the files are right there.
