**New in 0.2.22**

- **Scratch pad:** a new tile on the home page opens a Markdown scratch pad kept in `~/.config/mcp-docs`. Its menu lists your scratch pads and makes new ones, named for the day (`Scratch pad-oct23.md`). Opening one keeps the folder you were in, so the breadcrumbs lead back to it.
- **Open in a new tab from any editor:** each editor's File menu now starts with Open Folder… and Open file by path…, which open in a new tab and leave the file you're editing where it is.
- **Easier folder moves:** the file list starts with a ".." row to go up a folder; the breadcrumbs show the folder and the one above it, with full paths when you hover; and a Home button goes to your home folder.
- Smaller tiles on the home page.
