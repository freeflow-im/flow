**New in 0.2.17**

- **Your web files in the app:** a Web tab shows your Universal Docs account beside the folders on your computer, in the same window. A Local | Web switch beside the logo goes from one to the other, and each tab's title says which it is. Sign in with your email and password in the tab, or with Google, which finishes in your browser and signs the tab in by itself. File › Open Web Tab and File › Sign Out of Web are in the menu.
- **Copy files between your folder and the web:** Upload to Web… on a file in the folder copies it into one of your web folders, pictures and all. Download to Folder… on a web file copies it into a folder on your computer as a Word, PowerPoint or Excel file, in MCP Docs' own format (which keeps everything), or as a PDF; the dialog says what an Office file would not keep. Download to MCP Docs on the web does the same from any browser. A copy is a new file: changing one does not change the other.
- **Download as PDF:** documents, presentations, Markdown files and saved web pages download as a PDF in one click (File › Download as PDF, or the file's menu in the list), laid out as they print. Agents can make one too with the new `export_pdf` tool, which keeps the PDF next to the file.
- **Printing fixes:** Markdown and documents no longer print at slide size, and documents no longer print the page thumbnails.
