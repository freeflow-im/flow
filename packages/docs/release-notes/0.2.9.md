**New in 0.2.9**

- **Settings, simpler:** choose **Use an API key** (Anthropic, OpenAI or OpenRouter) or **Use a local coding agent** (the Claude Code installed on this Mac), then pick the key or the agent.
- **File › Settings…** (⌘,) opens Settings.
- **Reconnecting agents:** an agent connected before the app was removed and installed again (for example after `npx @scottpersinger/mcp-docs --uninstall`) is no longer refused as "Unknown agent"; the app asks you to allow it again.
