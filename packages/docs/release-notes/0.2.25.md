**New in 0.2.25**

- **Windows:** MCP Docs now comes for Windows (x64) as well: download `MCP-Docs-0.2.25-win-x64-setup.exe` below, or run `npx @freeflow-im/mcp-docs`, which installs it and the Claude Code and Codex plugins. This is its first release on Windows; Recents from the system and Make Default App… are Mac-only for now.
- **Pictures in Markdown:** the preview now shows a picture named by a path relative to the document (`![](images/chart.png)`), as GitHub does.
