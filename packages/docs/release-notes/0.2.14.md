**New in 0.2.14**

- **Copy pictures from slides:** copying a picture on a slide (⌘C or Edit › Copy) puts it on the clipboard, cropped as it shows, so you can paste it into other apps.
- **Right-click menu on slides:** right-click an element for Copy, Paste, Duplicate, Delete and the Arrange commands, plus Crop and Edit image for a picture. On the empty slide it offers Paste and Select all.
