**New in 0.2.16**

- **Find (⌘F) in documents, Markdown, JSON and presentations:** the same find bar as spreadsheets, with every match highlighted, Enter and Shift+Enter to step through them and Match case. In a presentation it searches every slide's text, tables included, and goes to each match's slide; in Markdown it marks the matches in the text and the preview; in a JSON file it opens the parts that hold a match. Closing it in a document or Markdown selects the match shown.
