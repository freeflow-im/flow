# Product tour

This is an outline/source of truth for the product tour slidedeck that we ship with the MCP Docs product.

## Local vs. Web

Explain that running the MCP Docs local app means accessing files on the local file system. But the app can also connect to the _cloud_ and access the cloud-deployed (multi-tenant) app. The cloud version can also be reached from your browser.

## Working with files

Running locally all files are present. On the web you need to add files into your account.

On either version you can click "New <doc>", or "Import" to add a file.

Pro tip: paste an image from your clipboard to import a new image file. Also works with text. 

Use the search bar or "cmd-p" to quickly search for a file.
