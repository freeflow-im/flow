# MCP Docs promo

## Intent

Concept #1, "The action log": the story is told by the assistant's own checklist. Each step ticks off and the
camera jumps to the screen it changed. The close borrows concept #2: `npx @freeflow-im/mcp-docs` typed as the
install shot.

The main message is the user's own wording: "A universal editor for any file, for humans and agents".

Order: agent demo (~22s) → "any file" section, each editor with a human edit (~8s) → message (~5s) → install
close (~5–8s).

Opening adjusted from the pitch: the skill's guide treats a prompt box as the first frame as a generated-film tell,
so the film opens on the dense PDF page (the need) and the prompt is typed ~1.5s in.
