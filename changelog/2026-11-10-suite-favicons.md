# The suite's new favicons

- `[web]` Every app has its own browser-tab icon from the new set (violet squircles): the suite mark at the root (Chat and the sign-in), Mail, Calendar, Docs (the files mark), and the suite mark for Contacts and Admin; as SVG, ICO and PNG, with an Apple touch icon each. Each app's page names its own files under its base path, since Vite leaves these paths as written.
- `[web]` Docs' tab shows the kind of file open: document, spreadsheet, presentation, Markdown (the document mark), and now picture and PDF too.

## Feature

- The FreeFlow apps have new tab icons: one for each of Chat, Mail, Calendar and Docs, and Docs' tab shows a small mark for the kind of file you have open, including pictures and PDFs.
