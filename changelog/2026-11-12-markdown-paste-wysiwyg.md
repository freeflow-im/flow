# Markdown editor: paste pictures, edit in the preview

- `[web]` `[desktop]` A picture pasted or dropped into a Markdown document (text or preview), or picked with
  Insert › Picture from computer…, is stored beside the document and linked by its relative path.
- `[web]` `[desktop]` The preview is editable in place; only the edited block's Markdown is rewritten, so the
  rest of the file keeps its exact text. Front matter and Mermaid diagrams stay text-only.
- `[web]` Relative pictures in an organization's Markdown document are read from that organization's files.

## Feature

- **Paste pictures into Markdown.** Paste or drop a screenshot or picture into a Markdown document and it is
  saved next to the document and shown in place.
- **Edit Markdown in the preview.** Type straight into the rendered preview — headings, lists, tables, code and
  task boxes — and the Markdown text follows.
