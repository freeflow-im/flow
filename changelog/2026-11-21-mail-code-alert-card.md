# Mail: sign-in code notifications stay, plus an alert card

- `[web]` `[desktop]` The sign-in code notification now stays until closed (`requireInteraction`); Mail also shows the code as an alert card under the suite bar with Copy code and Open message, even without desktop permission.
- `[web]` Suite alert actions can be buttons (`onClick`, no `href`).

## Feature

- **Sign-in code notifications are easier to see.** The desktop notification now stays until you close it, and Mail shows the code in a card at the top of the page with Copy code and Open message buttons.
