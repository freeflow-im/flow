# Docs' per-kind favicons, framed

- `[web]` Docs' browser-tab icons for a document, Markdown, presentation, spreadsheet, PDF and picture are the suite set's framed versions: the kind's mark inside the violet outline. The files mark on the home page is unchanged.

## Feature

The browser tab for an open document, spreadsheet, presentation, PDF or picture in Docs now shows the refreshed icon for that kind, framed to match the rest of the suite.
