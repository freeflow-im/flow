# Unread dot on the Chat tab's favicon

- `[web]` Chat's tab icon gets a small red dot while any workspace has unread notifications (the rail/dock badge count), and goes back to the plain icon at zero. Taskboard task 20.

## Feature

- **See waiting messages from the tab bar.** When something in Chat is waiting for you, the Chat tab's icon shows a small red dot, so you can spot it from another tab. It clears once you've caught up.
