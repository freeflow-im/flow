# Mail: darker, sturdier message text

- `[web]` Reader body text (plain and HTML messages) is now near-black `#111`, weight 450, with normal font smoothing in place of the app's thin grayscale smoothing. HTML messages default to 15px to match plain ones.

## Feature

- **Easier-to-read mail.** The text of a message in Mail is darker and slightly heavier, so it no longer looks washed out.
