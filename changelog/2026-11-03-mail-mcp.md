# Mail tools on app.freeflow.im/mcp, and drafts in Mail

- `[edge]` New OAuth scopes `mail:read`, `mail:write`, `mail:send`; the consent page has checkboxes (Docs files and Mail on, Send email as you off, with a warning). Existing tokens keep their scopes.
- `[edge]` `/mcp` lists Mail tools by scope, acting on the caller's own Mail object: search (Gmail syntax on Gmail), read, mark, move, archive, move to tab, trash (never expunged), drafts, send (`mail:send` only), and saving an attachment to Docs. Tools a scope does not allow are not listed.
- `[edge]` Mail API: `POST/DELETE /drafts`, `POST /drafts/:uid/send`, `raw=1` and `unread=1` on lists, `trashOnly` on delete, `attachFrom` and `replacesDraft` on send.
- `[edge]` The Docs assistant on the Worker can search and read mail, write drafts and save attachments (never send).
- `[web]` Mail: Edit draft on a message in Drafts opens it in Compose; sending it removes the draft.

## Feature

- **Let your agent handle your email.** When you connect an agent (Claude, Codex, ChatGPT) to FreeFlow, you can now let it read, search and organise your mail and write drafts for you to review. Sending email as you is a separate choice, off unless you tick it.
- **Edit drafts in Mail.** Open a message in Drafts and click Edit draft to finish and send it, including drafts your agent or the assistant wrote.
