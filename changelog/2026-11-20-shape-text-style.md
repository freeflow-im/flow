# Slides: style the text inside a shape from the toolbar

- `[web]` Selecting a shape now shows Bold, Italic, Font, Size and Text color for its label (`textBold`,
  `textItalic`, `textFont`, `textSize`, `textColor`); before, only the assistant could set them.

## Feature

- **Style the text in a shape.** In Slides, select a shape to change its text color, font, size, bold and
  italic from the toolbar.
