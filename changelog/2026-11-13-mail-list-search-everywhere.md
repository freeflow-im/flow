# Mail: one search field, beside the folder name, in the full app too

- [web] The full Mail app searches from the list's field beside the folder name, as Home does; the suite bar on Mail no longer has its own search. `/` focuses the field, Escape or emptying it ends the search.

## Feature

In Mail, the search box now sits next to the folder name (such as "Inbox"), the same as on the Home page. Press / to jump to it and Escape to clear it.
