# Calendar: HTML event descriptions

- [web] Event descriptions stored as HTML (Google Calendar, the Zoom add-on) show as text: line breaks, lists, `&amp;` and links with their own words, not raw tags.
- [web] The Zoom add-on's "This is a Zoom meeting. Click this link to join" text is read into the video-call row, like "Join Zoom Meeting".

## Feature

Calendar event descriptions from Google Calendar and Zoom now show with their line breaks, lists and links, instead of HTML code.
