# Docs: a folder panel on the left

- `[docs]` In FreeFlow, Docs has a left panel on every page: Recents, Favorites, and the folder tree of Organization files and My files. Choosing a folder lists its files beside it; opening a file keeps the panel, with the file's folder still selected. Drag its right edge to make it wider or narrower (double-click resets it); the width is remembered.
- `[docs]` The home page's Organization files / My files switch and its Recents and Favorites tabs moved into the panel. The desktop app and the standalone app are unchanged.
