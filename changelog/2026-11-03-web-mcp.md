# Docs' MCP endpoint on app.freeflow.im, with the organization chosen when an agent is allowed

- `[edge]` `/mcp` (and `/mcp/v2`), `/oauth/*` and `/.well-known/oauth-*` on the ported hosts: OAuth in the directory object (`mcpOAuth.ts`, migration 5) with FreeFlow's session for sign-in and the organization chosen on the consent page, carried by every code and token; `/mcp` runs the plugin's tools in that organization's Docs object, on its Organization files and the person's My files. `docs.` and `mcpdocs.` keep the plugin's `/mcp` on AWS.
- `[edge]` A token stops working when its person leaves the organization. `/api/settings/agents` lists the connected agents with their organization, and disconnects them.
- `[web]` Docs' Settings, Connect your agent, shows each agent's organization.

## Feature

- **Connect an agent to FreeFlow Docs.** Add `https://app.freeflow.im/mcp` to Claude Code, Codex, Cursor or another agent as a remote MCP server. You sign in with your FreeFlow account and choose which organization it works in; it can then read and edit that organization's files and your own, the same ones you see in Docs. Settings, Connect your agent, lists your agents and disconnects them.
