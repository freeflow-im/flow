# Docs: one search, in the suite bar

- `[suite-bar]` `SuiteSearch` can be live (`value`, `onChange`): the bar reports each change, stays open while it has text and keeps it on Enter; `openSuiteSearch(text)` opens it from elsewhere on the page.
- `[docs]` In the suite the home page has no search box of its own: the bar's search filters the list as you type (`?q=`) and Enter looks in every folder (`&find=1`); a key typed on the page opens the bar's search; Find (⌘P) and ⋯ moved into the list's toolbar.

## Feature

- **One search box in Docs.** The search at the top of FreeFlow now searches your files on the Docs home page: type to filter the list, press Enter to look in every folder. The second search bar under it is gone.
