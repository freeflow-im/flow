# /mcp is the FreeFlow server: Chat, Meet and one search join Docs, Mail and Calendar

- `[server]` `/mcp` runs in the Worker as `freeflow` / "FreeFlow" (mcp/suite.ts), no longer inside the Docs object; Docs tools run in the Docs object over RPC (`Docs.runMcpTool`).
- `[server]` Chat at `/mcp` (`chat:read`, `chat:write`): read, search, post, react, make channels, invite; never DMs. A personal agent posts as its own member and then shows on Chat's roster.
- `[server]` Meet at `/mcp` (`meet:read`, `meet:write`): `create_meeting`, `list_live_meetings`.
- `[server]` `search` (`search:use`) asks each app's search the token can run and merges the hits.
- `[web]` Consent and device pages say FreeFlow, not Docs; disconnect points to Admin, Connect an agent.

## Feature

- **Your AI agent can use all of FreeFlow.** An agent you connect (Claude, ChatGPT, Cursor and others) can now read and post in Chat, make meeting rooms, and search across your files, messages, email, contacts and calendar at once, beside Docs, Mail and Calendar. You choose what it may use when you connect it. Its Chat posts show under its own name, marked as an agent.
