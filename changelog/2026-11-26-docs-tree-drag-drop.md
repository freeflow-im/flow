# Docs: drag a file onto a folder of the folder tree

- `[web]` `[desktop]` A file dragged from the Docs list can be dropped on a folder of the same root in the left folder tree, which highlights it and opens a closed folder the drag rests on; the list reloads after the move.

## Feature

- **Drag files into folders from the sidebar.** In Docs, drag a file from the list onto any folder in the folder panel on the left to move it there. The folder lights up as you hover, and a closed folder opens if you rest on it so you can reach the folders inside.
