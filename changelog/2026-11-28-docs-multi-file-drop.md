# Docs: drop several files on a folder at once

- `[web]` `[desktop]` The Docs file list imports every dropped file, one after another, with a progress card in the corner (each file's state and an overall bar). A drop of several opens none of them, and a single-file drop still opens the file.
- `[web]` The ChatGPT plugin's library takes several dropped files the same way.

## Feature

- **Drop several files at once.** Drag a batch of files from your computer onto a Docs folder and they all upload. A small card in the corner shows each file's progress. Dropping just one file still opens it as before.
