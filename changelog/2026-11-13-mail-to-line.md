# Mail: the "to" line names everyone a message went to

- [web] The line under a sender now lists To, Cc and Bcc recipients by first name (the address when there is no name), on one line cut off with "…", as Gmail does. It used to list only To, by full name.

## Feature

- In a conversation, the "to" line under each sender now shows everyone the email went to, by first name, not only the first person.
